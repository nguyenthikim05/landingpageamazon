# MAYTREDAN — Landing Page Resource Pack

Dùng cho landing page HTML/CSS/JS, React, Next.js, Vue hay dự án có sẵn. **Không bao gồm mã nguồn landing page** vì chưa được cung cấp.

## Files
- `landing-content.en.json`: nội dung các section, sản phẩm, SEO và ô ảnh cần map.
- `brand-tokens.css`: biến màu để tích hợp vào hệ CSS hiện tại.
- `assets/maytredan-logo-original.png`: logo nguyên bản do chủ thương hiệu cung cấp.
- `assets/maytredan-brand-symbol-512.png`: biểu tượng cắt từ logo, dùng nếu phù hợp giao diện.
- `assets/favicon-64.png`: favicon tham khảo từ biểu tượng thương hiệu.
- `PROMPT_VSCODE.md`: prompt đầy đủ để agent trong VS Code thay thế trực tiếp.

## Steps
1. Giải nén toàn bộ thư mục `maytredan_landing_assets` vào thư mục gốc của dự án web.
2. Mở AI coding agent của VS Code, dán nguyên văn file `PROMPT_VSCODE.md`.
3. Đảm bảo các ảnh sản phẩm thật của bạn nằm trong dự án, để agent có thể map ảnh vào những vị trí phù hợp.
4. Kiểm tra lại thông số và link bán hàng trước khi đưa website lên production.
